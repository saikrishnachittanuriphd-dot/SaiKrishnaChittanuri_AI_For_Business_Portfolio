## Reflection<br>
One question connects all seven projects for me: what happens when a model makes a mistake? The machine learning review introduced the importance of defining the prediction task. The classification project made that idea concrete. When I built a classifier to recognize handwritten threes, I saw how a model could achieve high accuracy simply because most images contained another digit. Reading the confusion matrix helped me distinguish the threes the model missed from the other digits it incorrectly labeled as threes.<br>
The support vector machine and decision tree projects gave me practice tuning models and explaining their predictions. Comparing predicted and actual labels helped me see how tuning affected individual examples. With decision trees, I could follow the sequence of splits that led to a prediction and explain that reasoning to someone unfamiliar with the model. In the dimensionality reduction project, I explored how PCA could compress image features and used t-SNE to visualize which handwritten digits clustered together. The neural network project taught me how to use validation performance to decide when to stop training.<br>
The SMS spam classifier is the project I would show an employer first because it connects data preprocessing to a decision people experience every day. I cleaned and tokenized messages, converted the text into numerical features, and used the same preprocessing steps when classifying a new message. A missed spam message and a legitimate appointment reminder sent to spam have different consequences. That distinction will guide how I evaluate real-world ML systems, choose metrics, and explain trade-offs to business stakeholders.<br>
## AI Statement<br>
I used ChatGPT as a learning aid during these projects. In the neural network assignment, I used it to clarify how TensorFlow and Keras represent a network, how early stopping uses validation data, and how TensorBoard displays training progress. I also used it to help prepare visualization code. For this final portfolio, I used generative AI to organize the project notebooks and draft a reflection grounded in the work they contain.<br>
